La conjetura de Collatz: simple de escribir, imposible de probar

20 oct 2026 · 6 min de lectura

Toma cualquier entero positivo. Si es par, divídelo entre 2. Si es impar, multiplícalo por 3 y súmale 1. Repite. La conjetura afirma que, sin importar con qué número empieces, siempre llegarás a 1.

Formalmente, definimos la función:

$$ f(n) = \begin{cases} n/2 & \text{si } n \equiv 0 \pmod 2 \\ 3n + 1 & \text{si } n \equiv 1 \pmod 2 \end{cases} $$
Paul Erdős dijo sobre este problema: «las matemáticas aún no están preparadas para tales problemas».

En código

def collatz(n):
    pasos = 0
    while n != 1:
        n = n // 2 if n % 2 == 0 else 3 * n + 1
        pasos += 1
    return pasos

print(collatz(27))  # 111 pasos

¿Por qué es difícil?

Los pasos $n \to 3n+1$ hacen crecer el número, mientras que $n \to n/2$ lo reduce. Heurísticamente, en promedio cada par de pasos multiplica por $\sqrt{3}/2 \approx 0.87 < 1$, así que esperaríamos que las trayectorias bajen. Pero «esperar» no es demostrar: la conjetura se ha verificado por computadora hasta más de $2^{68}$ y sigue abierta.
